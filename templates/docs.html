📘 System Documentation & User Guide

🔍 Platform Overview

This AI-powered cybersecurity platform integrates multiple security layers including password analysis, network monitoring, intrusion detection, and real-time malware behavior tracking into a single intelligent system.

🔐 Password Security Module

What it does:

  • Analyzes password strength using entropy
  • Estimates crack time
  • Generates secure passwords
  • Enhances weak passwords (AI-based improvement)

How to use:

  1. Enter password
  2. Click Analyze
  3. View strength & crack time

🌐 Network Packet Analyzer

What it does:

  • Analyzes PCAP / CSV files
  • Detects suspicious IP traffic
  • Uses ML anomaly detection
  • Generates charts + PDF reports

How to use:

  1. Export file from Wireshark
  2. Upload file
  3. Click Analyze

🛡️ Mini-SOC IDS

What it does:

  • Detects brute-force attacks
  • Identifies credential stuffing
  • Geo-IP based risk detection
  • ML anomaly detection

How to use:

  1. Upload log file
  2. Click Analyze
  3. View threat score

🦠 AI Behavioral Malware Detection

What it does:

  • Monitors files in real-time
  • Detects abnormal behavior patterns
  • Identifies ransomware-like activity
  • Calculates global threat score

How to use:

  1. Click Start Monitoring
  2. System tracks file activity
  3. Alerts shown in real-time

🧠 AI & Machine Learning

The system uses Isolation Forest algorithm to detect anomalies in data. It learns normal behavior patterns and flags unusual activities such as abnormal traffic, login attempts, and file behavior without predefined rules.

📊 Threat Score Meaning

  • 0–30: Low Risk (Safe)
  • 30–60: Medium Risk
  • 60–100: High Risk
